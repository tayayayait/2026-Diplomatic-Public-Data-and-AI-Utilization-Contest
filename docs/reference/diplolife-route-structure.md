## Removed User Routes

- `/trips`
- `/trips/new`
- `/trips/$tripId/confirm`
- `/trips/$tripId/analyzing`
- `/trips/$tripId/dashboard`
- `/trips/$tripId/checklist`
- `/trips/$tripId/emergency`
- `/trips/$tripId/countries/$countryIso2`
- `/share/$shareId`

The backing engine modules are not removed in Phase 2. Public-data, Gemini, weather, exchange-rate, country, and SOS-related modules are retained for later screen integration.

## Verification

- `src/lib/diplolife/route-structure.test.ts` checks the route-file boundary.
- `tests/e2e/diplolife-routes.spec.ts` replaces the stale SafeRoute E2E route coverage.
- `src/routeTree.gen.ts` must be regenerated by the TanStack Router plugin through `npm run build` or the dev server.

## Out Of Scope For Phase 2

- Final AppShell navigation.
- Real authenticated onboarding persistence.
- Data binding for dashboard, chat, SOS, cost, safety, visa, and notices.
- Removing unused SafeRoute engine modules that are still candidates for reuse.
